### 部署

!!需要安装bun

首先，Clone项目后在项目根目录运行:

```bash
bun install
```

稍等片刻，依赖安装完成后运行:

```bash
bun run dev
```

最后访问 [http://localhost:3900](http://localhost:3900) 即可
