## 这是什么？

这是EQAD服务器官网的仓库，欢迎大家来提交PR，共同完善这个网站。同时，也欢迎大家使用这个网站作为模板来制作属于自己的MC服务器官网

*该网站基于 [桃花源服务器官网](https://ranmc.cc/) 二改*

## 部署

!!需要安装bun

首先，Clone项目后在项目根目录运行:

```bash
bun install
```

稍等片刻，依赖安装完成后运行:

```bash
bun run dev
```

最后访问 [http://localhost:3100](http://localhost:3100) 即可
